# Security policy

## Data handling

All log samples in `tests/events/` are **synthetic**. They were written by hand for testing and contain
no real hostnames, users, IP addresses or company data. IP addresses use documentation ranges (RFC 5737).

## Reporting an issue

If you find a detection bypass, a false-positive storm, or anything sensitive committed by mistake,
please open a GitHub issue — or, for anything sensitive, use the **"Report a vulnerability"** button
in the repository's *Security* tab so it can be handled privately.
